EXPERIMENT NO. 1

1. Experiment Title

Variables in JavaScript

2. Aim

To declare and initialize variables using let, const, and var in JavaScript.

3. Software / Tools Required

Visual Studio Code, Google Chrome Browser

4. Theory

Variables are containers used to store data in JavaScript. The let and const keywords were introduced in ES6. The let keyword allows reassignment of values, whereas const does not allow reassignment. The var keyword is the older way of declaring variables and has function scope.

5. Algorithm / Procedure

1. Create a folder named Assignment 1.
2. Create an HTML file named index.html.
3. Add a script tag inside the HTML file.
4. Declare let a = 10, const name = "Utkarsh Yadav", and var roll = BCS2025381.
5. Display the variables using console.log().
6. Open the file in Google Chrome.
7. Open the browser console using Ctrl + Shift + J.
8. Observe the output and take a screenshot.

6. Program / Queries / Commands

index.html

</html>
