## 1. Aim of the Experiment
To gain practical experience with JavaScript arrays, accessing elements by index, iterating using `forEach`, filtering arrays with higher-order functions (`filter`), and accessing elements in multi-dimensional (nested) arrays.

---

## 2. Concepts Covered
- Array declaration and accessing `.length`.
- Zero-based index positioning.
- Iterative operations using `Array.prototype.forEach()`.
- Immutable array transformations using `Array.prototype.filter()`.
- Multi-dimensional (2D) nested arrays and matrix indexing (`matrix[row][col]`).

---

## 3. Task-wise Description
- **Task 1 (`Task1.js`):** Create `marks` array `[72, 85, 64, 90]`. Print the number of items and the first mark.
- **Task 2 (`Task2.js`):** Create `subjects` array `["Maths", "Science", "English"]`. Use `forEach` to print every subject.
- **Task 3 (`Task3.js`):** Create `marks` array `[72, 85, 45, 90]`. Use `filter()` to create a new array with marks >= 60 and print it.
- **Task 4 (`Task4.js`):** Create a 2D array `grid = [[1, 2, 3], [4, 5, 6]]`. Access and print the number located in row 2 and column 3 (`grid[1][2]`).
