## 1. Aim of the Experiment
To gain proficiency in using JavaScript conditional structures (`if-else if-else`) for decision making and iterative control structures (`for` loop and `while` loop) for repetition and accumulation.

---

## 2. Concepts Covered
- Conditional branching with `if`, `else if`, and `else`.
- Deterministic iteration using the standard `for` loop.
- Indefinite/conditional iteration using the `while` loop.
- Accumulator pattern and termination conditions.

---

## 3. Task-wise Description
- **Task 1 (`Task1.js`):** Store marks as `72`. Determine and print the student grade: "Grade A" for marks >= 75, "Grade B" for marks >= 60, and "Grade C" otherwise.
- **Task 2 (`Task2.js`):** Iterate from 1 through 5 using a `for` loop and print each number on a new line.
- **Task 3 (`Task3.js`):** Use a `while` loop to successively add consecutive integers (1, 2, 3, ...) until the accumulated total exceeds 20. Print the final accumulated total.

---
