## 1. Aim of the Experiment
To understand different ways of declaring and invoking JavaScript functions, including standard function declarations, ES6 arrow functions, and functions utilizing default parameter values.

---

## 2. Concepts Covered
- Function declaration syntax and return statements.
- ES6 Arrow functions (`=>`) with implicit/concise return bodies.
- Default parameters in ES6 function signatures.
- Practical business logic calculations (bill with tax).

---

## 3. Task-wise Description
- **Task 1 (`Task1.js`):** Create function `greet(name)` that returns `"Hello, [name]"`. Call and print `greet("Asha")`.
- **Task 2 (`Task2.js`):** Create an arrow function named `square` that returns a number multiplied by itself. Call and print `square(6)`.
- **Task 3 (`Task3.js`):** Create function `billWithTax(amount, taxRate)` where `taxRate` defaults to `0.18`. Call and print `billWithTax(100)`.
