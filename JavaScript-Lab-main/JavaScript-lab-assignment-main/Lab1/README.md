## 1. Aim of the Experiment
To get started with JavaScript programming by embedding a script within an HTML document, declaring variables using modern ES6 keywords (`const` and `let`), and inspecting primitive data types using the `typeof` operator.

---

## 2. Concepts Covered
- Embedding JavaScript in HTML using the `<script>` tag.
- Outputting messages to the browser console using `console.log()`.
- Declaring constants with `const` and re-assignable variables with `let`.
- Identifying primitive JavaScript data types (`string`, `number`, `boolean`) using the `typeof` operator.

---

## 3. Task-wise Description
- **Task 1 (`Task1.html`, `Task1.js`):** Create an HTML document containing a `<script>` tag inside the `<body>` element. Use `console.log()` to output `"Hello from the script"`.
- **Task 2 (`Task2.js`):** Declare `const schoolName = "Sample College"` and `let year = 2026`. Print both variables on separate lines to the console.
- **Task 3 (`Task3.js`):** Evaluate and print the data types of `"hello"`, `7`, and `true` using the `typeof` operator.

## 5. How to Run the Programs

### Running in a Web Browser:
1. Double-click or open `Task1.html` in any web browser (Google Chrome, Microsoft Edge, Mozilla Firefox).
2. Open the Developer Tools console by pressing `F12` or `Ctrl + Shift + I` and navigating to the **Console** tab.

### Running with Node.js (if installed):
Open your terminal in this directory and run:
```bash
node Task1.js
node Task2.js
node Task3.js
```
