## 1. Aim of the Experiment
To understand and implement basic arithmetic operators, explore explicit type conversion between strings and numbers, and build a simple conditional calculator logic using `if` and `else if` statements.

---

## 2. Concepts Covered
- Arithmetic operations: addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
- Type conversion methods: `Number()` for converting string literals to numeric values, and `String()` for converting numeric primitives to text.
- String concatenation vs. arithmetic addition.
- Conditional flow control using `if` and `else if`.

---

## 3. Task-wise Description
- **Task 1 (`Task1.js`):** Perform arithmetic operations with numbers 17 and 5 to calculate and print their sum, difference, product, and quotient.
- **Task 2 (`Task2.js`):** Demonstrate explicit type conversion by converting `"12"` to a number to add `5`, and converting `7` to a string to concatenate with `"3"`.
- **Task 3 (`Task3.js`):** Implement calculator logic for numbers 8 and 4 using `operator = "+"`. Evaluate using `if` and `else if` to print the sum. Change the operator to `"-"` and repeat the check to print the difference.
