## 1. Aim of the Experiment
To gain an understanding of JavaScript object manipulation, property access, property mutation, and modern ES6 destructuring assignment syntax for both arrays and objects.

---

## 2. Concepts Covered
- JavaScript object literals, key-value pairs, and property mutation.
- ES6 Array Destructuring syntax (`[a, b] = array`).
- ES6 Object Destructuring syntax (`{ key1, key2 } = object`).

---

## 3. Task-wise Description
- **Task 1 (`Task1.js`):** Create an object with `name: "Rohan"`, `roll: 12`, and `marks: 78`. Print `name`, update `marks` to `81`, and print `marks` again.
- **Task 2 (`Task2.js`):** Create array `subjects = ["Maths", "Science", "English"]`. Destructure to extract the first and second elements, and print both separately.
- **Task 3 (`Task3.js`):** Create object `student` with `name: "Rohan"`, `roll: 12`, and `marks: 81`. Use object destructuring to extract `name` and `roll`, and print both separately.
